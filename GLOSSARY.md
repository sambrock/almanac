# Almanac

Almanac is a personal app for recording your life. The journal is the first feature.

## Journal

**Journal**:
Everything a user has written, organised by day. Each user has one.
_Avoid_: Diary, notebook

**Entry**:
What a user wrote for one journal date. A journal date has at most one entry.
_Avoid_: Note, post, page, day

**Entry title**:
A few words naming what an entry is about. AI writes it from the entry, and the user can't edit it.
_Avoid_: Summary, heading, subject

**Entry summary**:
A few bullet points AI writes about an entry when the user presses Done, along with its title: what happened, and what the user felt, decided or meant to do. The user reads it at the end of the entry. Follow-ups read the summaries of earlier entries to bring up what the user wrote before. The user can't edit it.
_Avoid_: Recap, takeaways, memory

**Reflection**:
The follow-ups in an entry together with the user's answers, read in order. It starts when the user presses Go deeper.
_Avoid_: Chat, conversation, thread

**Follow-up**:
What AI adds to the end of an entry when the user presses Go deeper: a sentence or two responding to the entry or the last answer, then one question. It shows in the entry in blue, but isn't part of the entry's text. Once an entry has one, everything the user wrote before it is locked.
_Avoid_: Prompt, insight

**Answer**:
What the user writes below a follow-up. Only the answer to the latest follow-up can be edited.
_Avoid_: Reply, response

**Entry snapshot**:
A copy of an entry's saved content at a particular moment.

**Journal date**:
The calendar day an entry belongs to, in the user's own time zone.
_Avoid_: Created date, timestamp
