# Almanac

Almanac is a personal app for recording your life. The journal is the first feature.

## Journal

**Journal**:
Everything a user has written, organised by day. Each user has one.
_Avoid_: Diary, notebook

**Entry**:
What a user wrote for one journal date. A journal date has at most one entry.
_Avoid_: Note, post, page, day

**Journal date**:
The calendar day an entry belongs to, in the user's own time zone.
_Avoid_: Created date, timestamp
